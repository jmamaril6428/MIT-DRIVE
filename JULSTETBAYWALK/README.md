# Beachside Property Photo Gallery

A responsive, GitHub Pages-ready photo viewer inspired by the supplied screenshot.

## Files
- `index.html`: semantic HTML structure
- `style.css`: desktop/mobile layout and thumbnails
- `script.js`: working photo navigation, edit preview, keyboard shortcuts, share
- `photos/`: nine property photos

## Publish using GitHub Pages
1. Create a **public GitHub repository** (for example `beachside-property-gallery`).
2. Upload `index.html`, `style.css`, `script.js`, and the full `photos/` folder **to the repository root**.
3. In GitHub, go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
5. When published, the site URL will normally be `https://YOUR-USERNAME.github.io/beachside-property-gallery/`.
6. Share that link on Facebook, or separately upload the photos directly to Facebook.

**Note:** JavaScript is used for browser behavior. Java is a different language and is not needed for this static website.

**Edit button:** loads a replacement photo locally in the current browser only; it cannot save directly into your GitHub repository. Permanently update by replacing the JPG in `photos/` and committing the change.

**Photos:** enhanced/generated marketing images may differ slightly from the property's actual appearance. Review before using them in a commercial listing.
